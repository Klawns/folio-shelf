# Folio Shelf changelog

## 0.2.34

### Book records

- New book records show their purpose in Obsidian's inline title, for example **Book record - Designing Data-Intensive Applications**. Existing records keep their filenames.

## 0.2.33

### Study notes

- The confirmation button now shows progress while Folio Shelf creates and opens a study note. On desktop, the indicator stays visible while Folio Shelf also tries to open the book PDF.
- If creating a note fails, you can retry without retyping its filename.
- The book menu now uses **Open book record** for the book's reference note.
